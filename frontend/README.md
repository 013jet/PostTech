# JanaМен · Frontend

React + TypeScript + Vite. Вход, профиль, заявки и Academy подключены к локальному Fastify API и PostgreSQL.

## Запуск

Сначала запустить backend по [общей инструкции](../README.md). Затем в этой папке:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

[Кабинет](http://127.0.0.1:5173/). Прокси Vite передаёт `/api` на `127.0.0.1:3001`. Строки подключения к базе и серверные секреты во фронте не используются.

Вход: `employee@janamen.local`, `manager@janamen.local` или `hr@janamen.local`, пароль локальных аккаунтов — `JanaLocal2026!`. Для одновременных ролей использовать `127.0.0.1` и `localhost` либо отдельные профили браузера. На одном адресе cookie общая для всех вкладок.

HR-администратору доступны «Обзор заявок», «Сотрудники» с поиском, собственный профиль и личные уведомления. Заявки компании открываются для просмотра истории; решения принимает прямой руководитель. Личные контакты и результаты обучения коллег не выдаются сервером. AI Jana использует базу знаний версии 1.4 с инструкциями для отдельных аккаунтов и серверного сохранения.

## Подключённые разделы

- Вход, восстановление сессии и выход. Роль приходит с сервера; переключатель демо-ролей удалён.
- Главная и профиль: текущий пользователь, остаток, сохранение контактов через API.
- Свои заявки и заявки команды, фильтры, карточки и история.
- Создание отпуска, отзыв с подтверждением, повторная подача с новым номером, решение с обязательным комментарием.
- Проверки дат, пересечений и остатка в форме и независимо на сервере.
- Уведомления по заявкам, прочтение и переход к карточке.
- Academy: серверные материалы, прогресс, черновики ответов, проверка теста, история попыток, пересдача и уведомление о завершении.

Формы ждут ответа сервера, блокируют повторное нажатие и показывают ошибки. Повтор создания после потери ответа использует тот же ключ, чтобы не создавать дубликат. При конфликте или истечении сессии кабинет обновляется.

Снимок обновляется каждые 15 секунд при видимой вкладке, при возвращении в окно и по кнопке «Обновить данные». Это опрос API, без WebSocket. При потере связи показывается ошибка; после неудачной загрузки изменения блокируются до успешного обновления.

## Обучение и локальная база знаний

Academy получает назначения, материалы и прогресс из API. Ответы сохраняются на сервере при выборе варианта; во время запроса элементы формы блокируются. При конфликте с другим окном показывается ошибка и загружается актуальный прогресс. Оценку и разбор возвращает сервер; правильных вариантов до сдачи нет в клиентских данных. Прогресс: материалы и успешно сданный тест — отдельные шаги.

Старое браузерное сохранение не удаляется и не импортируется в PostgreSQL. Кабинет больше не читает и не записывает его: заявки, профили, обучение и все уведомления берутся из API. Старые обработчики прототипа сохранены только для регрессионных тестов.

AI Jana пока работает локально по тестовой базе знаний, без внешней AI-модели. Диалог не сохраняется после обновления.

## Проверки и файлы

```powershell
pnpm test
pnpm build
```

Проверяются прежние правила и HTTP-клиент: истечение сессии, конфликты, потеря связи, некорректный ответ прокси и повтор отправки. Серверные проверки прав, согласования и обучения — в `backend/test/`. Приватный учебный fixture для регрессионных тестов загружается Node.js из `backend/seed-data/`, не входит в клиентскую сборку.

- `src/ConnectedApp.tsx` — вход, загрузка сессии, обновления и выход.
- `src/api/client.ts` — тип снимка, HTTP-клиент и ошибки.
- `src/App.tsx` — кабинет, навигация и вызовы API.
- `src/components/`, `src/pages/` — готовые формы, карточки и страницы.
- `src/pages/CoursePage.tsx` — готовый интерфейс обучения с асинхронными действиями API и серверным разбором.
- `src/hooks/usePersistentWorkflow.ts`, `src/utils/storage.ts` — прежний прототип, не используется кабинетом.
- `src/mocks/` — локальная база знаний и примеры для регрессионных тестов; не источник серверных записей.
- `vite.config.ts` — локальный сервер и прокси API для dev/preview.

Интерфейс адаптивен. Внешних AI-сервисов и кадровых интеграций пока нет. Все записи вымышлены.
